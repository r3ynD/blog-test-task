# База данных

Структура для блога из тестового задания: категории, статьи и связь между ними.
Одна статья может относиться к нескольким категориям.

SQL создания таблиц: [001_create_blog.sql](migrations/001_create_blog.sql).
Все таблицы используют InnoDB и `utf8mb4`. Поля обязательные, `NULL` не используется.
В Docker используется MySQL 8.4; выборка последних статей на главной требует MySQL 8+.

## categories

| Поле | Тип | Назначение |
| --- | --- | --- |
| id | INT UNSIGNED | Первичный ключ, AUTO_INCREMENT |
| name | VARCHAR(150) | Название категории |
| description | TEXT | Описание категории |
| created_at | DATETIME | Дата создания, по умолчанию CURRENT_TIMESTAMP |

## articles

| Поле | Тип | Назначение |
| --- | --- | --- |
| id | INT UNSIGNED | Первичный ключ, AUTO_INCREMENT |
| image | VARCHAR(255) | Путь или URL изображения |
| title | VARCHAR(255) | Заголовок |
| description | TEXT | Краткое описание для списка статей |
| text | MEDIUMTEXT | Полный текст |
| views | INT UNSIGNED | Просмотры, по умолчанию 0 |
| published_at | DATETIME | Дата публикации для сортировки и последних статей |
| created_at | DATETIME | Дата создания записи, по умолчанию CURRENT_TIMESTAMP |

Дата публикации задаётся отдельно от даты создания записи.

## article_categories

| Поле | Тип | Назначение |
| --- | --- | --- |
| article_id | INT UNSIGNED | Внешний ключ на articles.id |
| category_id | INT UNSIGNED | Внешний ключ на categories.id |

Первичный ключ `(article_id, category_id)` запрещает повторно добавить статью
в ту же категорию. Индекс `(category_id, article_id)` нужен для поиска статей
категории. Первый ключ также позволяет искать категории статьи.

При удалении статьи или категории связанные строки из `article_categories`
удаляются автоматически. Удаление категории не удаляет сами статьи.
Индексы для сортировки добавим при реализации запросов, если план выполнения
покажет, что они нужны.

## Пример связи

Есть две категории: `1 — PHP` и `2 — Базы данных`.
Статья `10 — Как выбрать индекс для запроса` имеет изображение
`/assets/images/database.jpg`, краткое описание, полный текст,
`views = 0` и `published_at = 2026-01-10 12:00:00`.

Чтобы отнести её к обеим категориям, в `article_categories` нужны две строки:

| article_id | category_id |
| --- | --- |
| 10 | 1 |
| 10 | 2 |

Другие статьи из этих категорий могут попасть в блок похожих статей.
По заданному правилу сначала идут статьи с большим числом общих категорий,
затем — более свежие; текущая статья исключается, выводятся максимум три.

## Миграции и проверка

[bin/migrate.php](../bin/migrate.php) применяет SQL-файлы по порядку имён.
В служебной таблице `schema_migrations` хранятся `filename` (VARCHAR(255),
первичный ключ) и `applied_at` (DATETIME, по умолчанию CURRENT_TIMESTAMP).
При повторном запуске уже применённые файлы пропускаются.

[tests/database.php](../tests/database.php) проверяет повторный запуск миграций,
внешние ключи, уникальность связей и каскадное удаление на отдельной тестовой БД.

Демоданные лежат в [seeds/blog.php](seeds/blog.php). Команда `php bin/seed.php`
добавляет 12 статей и 4 категории, только если таблицы категорий и статей пустые.
Одна категория оставлена без статей для проверки главной.
